# Circadia
> Third Space Hack Club Week 4!

**Circadia**, an environmental and human presence monitoring smart device, it turns on when it detects the presence of someone and the light vibe is based on the surrounding atmosphere.

## 💠 Project Overview 💠
This weeks project theme is "Autumn", and so we thought, "Hmm, what hardware things can we make with this theme?" and then someone said its halloween related so we thought of a pumpkin emitting light, or some sort of nightlight or something. Anyways, Circadia. It can feel if there's people then it will turn on and shine light, then can change colour too. **Note from other guy: It can also do some astronomical math to calculate sun position and change the light to match it. ++Monitors dry indoor air. ++The light scales off the light from the environment!!

### **Key Features** 🗝️
- Calculates Solar Ephemeris (fancy way of saying position on the sun)
- Vapor Pressure Deficit Monitoring (humidity monitor 🙏)
- Fractional Brownian Motion for Ambient Light (random light patterns uses Perlin noise)
- LCD Display (cool display firmware i did)
