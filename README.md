# Circadia
> Third Space Hack Club Week 4!

**Circadia**, an environmental and human presence monitoring smart device, it turns on when it detects the presence of someone and the light vibe is based on the surrounding atmosphere.

## 💠 Project Overview 💠
This weeks project theme is "Autumn", and so we thought, "Hmm, what hardware things can we make with this theme?" and then someone said its halloween related so we thought of a pumpkin emitting light, or some sort of nightlight or something. Anyways, Circadia. It can feel if there's people then it will turn on and shine light, then can change colour too.
